# Central de Monitoramento – Apucarana (prévia)

Prévia, para validação, do app **Sistema de Monitoramento / Central de Monitoramento** do GeoAPUC (Prefeitura de Apucarana-PR).

- O app foi montado no ArcGIS Experience Builder Developer Edition 1.19.
- Os dados vêm do Portal da Prefeitura: câmeras, status, campo de visão e mapa base.
- Os vídeos vêm do servidor de streaming da Prefeitura.

Esta é uma versão provisória. A versão oficial será publicada em `geo.apucarana.pr.gov.br`.

## Mobilidade Urbana (prévia)

Prévia, para validação, do app **Mobilidade Urbana** do GeoAPUC: linhas, horários (dias úteis), paradas e tempo real (Mobilibus).
Acesso: https://jrnegrao.github.io/cctv/mobilidade/?locale=pt-br
Versão atual: v2 (visual no padrão dos widgets dos desenvolvedores; painel Serviços ao Passageiro). A v1 fica guardada em `mobilidade/cdn/1`.

## Ordenamento Territorial (prévia)

Prévia, para validação, do app **Ordenamento Territorial** do GeoAPUC: zoneamento de Apucarana com a Ficha da Zona (usos, ocupação e lote mínimo) e o modo "Onde posso…?", que mostra no mapa onde cada atividade é permitida ou tolerada.
Acesso: https://jrnegrao.github.io/cctv/zoneamento/?locale=pt-br
