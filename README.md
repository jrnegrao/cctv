# Central de Monitoramento – Apucarana (prévia)

Prévia, para validação, do app **Sistema de Monitoramento / Central de Monitoramento** do GeoAPUC (Prefeitura de Apucarana-PR).

- O app foi montado no ArcGIS Experience Builder Developer Edition 1.19.
- Os dados vêm do Portal da Prefeitura: câmeras, status, campo de visão e mapa base.
- Os vídeos vêm do servidor de streaming da Prefeitura.

Esta é uma versão provisória. A versão oficial será publicada em `geo.apucarana.pr.gov.br`.
